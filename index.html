CCFOLIA Character JSON 產生器

填寫角色資料 → 產生 Clipboard API JSON → 複製後貼到 CCFOLIA。

① 基本資料

角色名稱 name｜角色顯示名稱
備註 memo｜角色的備註文字
行動值 initiative｜行動值
外部連結 externalUrl｜網址

⑤ 位置與外觀

X 座標 x｜官方註記：預設值優先
Y 座標 y｜官方註記：預設值優先
旋轉角度 angle｜number
寬度 width｜number
高度 height｜number
顏色 color｜例如 #E0E0E0

⑥ 顯示設定

啟用 active｜boolean
不公開角色狀態 secret｜boolean
發言時不顯示角色立繪 invisible｜boolean
不要在盤面的角色清單中顯示 hideStatus｜boolean

⑦ 指令與擁有者

角色指令 commands｜貼入角色的 command
Owner owner｜擁有者；可留空
尚未建立 Room ZIP。

⑧ 最終 JSON

這裡的內容就是要複製後貼到 CCFOLIA 的 JSON 字串。

匯入外部角色 JSON

使用方式： 把 CCFOLIA / 外部工具匯出的角色 JSON 貼到下面。
支援一般 JSON，也支援 "{""kind"":""character""...}" 這種被 Excel / CSV 包過的格式。
匯入後會自動填入： 名稱、行動值、Status、固定變數、指令、備註、圖片、位置與顯示設定 。
