區分大小寫是什麼？
開啟後，英文字母的大小寫必須完全相同才會符合。
例如搜尋 Face：會找到 Face，不會找到 face 或 FACE。
關閉時則不區分大小寫，這些寫法都可能符合。

全字匹配是什麼？
開啟後，搜尋文字左右不能緊貼英文字母、數字或底線的一部分，避免只改到較長英文／數字名稱中的片段。
例如搜尋 cat：會匹配 cat，但不會匹配 cats 或 bobcat。
注意：這裡的「字」主要依英文字母、數字與底線判斷；中文名稱請以實際預覽結果確認。

正規表示式是什麼？
開啟後，搜尋內容會被當成規則，而不是一般文字。常用符號如下：
  • .：任意單一字元，例如 面. 可匹配「面A」「面1」。
  • *：前一個項目重複 0 次以上，例如 ab* 可匹配「a」「ab」「abb」。
  • +：前一個項目重複 1 次以上，例如 ab+ 可匹配「ab」「abb」。
  • \d：一個數字；\w：英文字母、數字或底線。
  • ^：文字開頭；$：文字結尾。
  • [abc]：匹配 a、b 或 c 其中一個字元；(a|b)：匹配 a 或 b。
差分名稱常用例子：
角色{N_}：匹配「角色12_」這種前綴；角色 {(N)}：匹配「角色 (12)」。
ABC{D}_：匹配「ABC01_」「ABC123_」；@藍色-：匹配以「@藍色-」開頭的名稱。
@?通常：開頭 @ 可有可無，可同時匹配「@通常」與「通常」。
智慧偵測會優先採用涵蓋名稱較多的共同前綴；相同數量時選擇較長的前綴，並忽略少數異格式名稱。
若只是要搜尋字面上的符號（例如 .、+），請關閉正規表示式；修改前先按「預覽」確認結果。
快捷鍵
常用範例（點一下，自動填入搜尋與取代）
快速插入規則（點一下就能使用）
{a} 一個英文字母；{A} 一段英文字母（A–Z、a–z）
{u} 一個 Unicode 字母；{U} 一段 Unicode 字母（包含中文、日文等文字）
{d} 一個 ASCII 數字；{D} 一串 ASCII 數字；{N} 零個或多個 ASCII 數字
{n} 一個 Unicode 數字；{Q} 一串 Unicode 數字
{(N)} 括號中的數字，例如 (12)；{N_} 數字加底線，例如 12_
{w} 一個 Unicode 字母、數字或底線；{W} 一段 Unicode 字母、數字或底線
{p} 一個標點符號；{P} 一段標點符號（例如底線以外的標點）
{h} 一個十六進位字元（0–9、A–F）；{H} 一段十六進位字元
{s} 一個空白；{S} 一段空白；{x} 一個非空白字元；{X} 一段非空白字元
{.} 任意一個字元。所有快捷符號只在勾選「正規表示式」時生效。
取代欄也有快捷符號：{0} 代表整段符合的文字，{1}、{2} 代表搜尋規則中第 1、2 個 ( ) 捕獲的內容。
例：搜尋 角色{D}、取代為 人物{0}，會把「角色123」改成「人物角色123」。若搜尋 角色({D})、取代為 人物{1}，則會改成「人物123」。
這些大括號快捷符號只會在勾選「正規表示式」時生效；其他正規表示式語法仍可直接輸入。
